# In Drama
> InDrama is a community service that helps users explore drama filming locations, discover nearby restaurants and attractions, create personalized travel itineraries, and share reviews and opinions with others.

## Key Features

### Drama Filming Location Search

- Auto-Complete Search
  > Users can search for dramas and click on desired drama to view its filming locations.
    
- Recent Drama Search
  > Users can scroll through recent drama posters and click on a desired drama to view its filming locations.   

### Planning a Travel Itinerary
<img width="1676" alt="Screenshot 2025-01-08 at 2 55 55 AM" src="https://github.com/user-attachments/assets/8415f18f-f386-41aa-9e8a-5bee43a52671" />

- Drag-and-Drop Based Tourist Spot Addition
  > Users can drag and drop nearby tourist spots around the selected drama filming location.

- Travel Itinerary Creation
  > Users can create and organize a travel itinerary by adding selected tourist spots. 

### Genre-Based Search
<img width="1649" alt="Screenshot 2025-01-08 at 2 42 50 AM" src="https://github.com/user-attachments/assets/f60a6b09-6349-473c-b22a-aba7041d96bd" />

- Genre-Based Search
  > Users can search for dramas based on specific genres to find and explore related filming locations.   

## Tech Stack

- Frontend:  React.js, Tailwind CSS, Redux
- Backend:   Spring Boot, JPA, MySQL
